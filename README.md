# AR Membership Manager

Automated membership dues tracking and renewal system with WhatsApp reminders and 1-tap UPI payment links. Built with **Next.js**, **React**, and modern **vanilla CSS design tokens**.

---

## ⚡ Features

- **Automatic WhatsApp Reminders**: Direct notifications sent via official Meta WhatsApp Cloud API.
- **Smart 3-Stage Cadence**: Automated sequence (1 day before, on due date, and 1 day overdue).
- **Flexible Payments**:
  - Direct UPI straight into your bank account with 0% gateway fee.
  - Cashfree checkout integration with automatic transaction marking and instant renewal.
- **WhatsApp Confirmations & Ledger**: Instant confirmation text messages and real-time searchable ledger with CSV/Excel export.
- **Interactive Sandbox & Dues Loss Calculator**: Built-in interactive dues recovery estimation tool.
- **Responsive Dark/Lime Aesthetics**: Custom mobile-optimized UI tailored for gyms, tuition academies, badminton/sports clubs, and monthly subscription businesses.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Styling**: Vanilla CSS Design System with Google Fonts (`Bricolage Grotesque` & `DM Sans`)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
